HW 3: A Pointer Library

HW 3 consisted of a library of four functions.

- ptr.h/ptr.c: swap_float, minmax, find_above, reverse
- tests/test_ptr.c: tests every function, including one value, n=0, NULL pointers, value equal to the threshold, and even/odd lengths
- Makefile: builds everything with gcc -std=c11 -Wall -Wextra

To build and test, inside the folder for HW 3, run the following: make, make test, make clean.
